# SolidityVerve

SolidityVerve is a blockchain-based smart platform for optimized gas streamlined smart contract deployment via API and library integration.

With SolidityVerve, you get a lightweight tool that stays out of your way.

**What you get**

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/SolidityVerve.git`
2. `cd SolidityVerve`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure SolidityVerve, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
